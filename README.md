# すうじ認識 — 手書き数字学習

手書き数字を認識する教材、苦手な数字を集めるツール、追加学習Notebookを含みます。

## 使い方

GitHub Pages等のHTTP(S)配信で `index.html` を開きます。モデルやTensorFlow.jsを読み込めるネットワーク環境が必要です。追加学習は [`finetune_mnist.ipynb`](finetune_mnist.ipynb) の説明を参照してください。

[`warizan_renshu_hint.html`](warizan_renshu_hint.html) は、ヒント付きのわり算・筆算教材です。「入力方法」で数字ボタンと手書きを切り替えます。手書きでは1けたずつ書き、読み取られた候補から書いた数字を選びます。商・あまりと筆算の途中計算に対応し、認識モデルは手書きを選んだときだけ読み込みます。

## データ・素材・クレジット

- NotebookはKerasの `tf.keras.datasets.mnist.load_data()` によるMNIST読み込みを記載しています。公式情報: [MNIST database](https://yann.lecun.org/exdb/mnist/index.html)。
- 公式ページではデータベース作者としてYann LeCun、Corinna Cortes、Christopher J. C. Burgesが示されています。MNISTおよび派生学習済みモデルの具体的な再配布条件は、このリポジトリで確認できていません。
- 同梱 `model/mnist.keras` の元モデル・学習記録は未特定です。Notebookにある学習方法と、同梱モデルの出所が同じとは確認できていません。
- TensorFlow.jsはCDNから読み込みます。バージョン指定が `@latest` のページがあります。Python側のTensorFlow/KerasおよびTensorFlow.jsは各プロジェクトのライセンスに従います。
- 手書きデータの収集・保存場所はアプリの設定/画面を確認してください。個人の筆跡を共有・再配布する前に、本人の同意とデータ公開条件を確認してください。
